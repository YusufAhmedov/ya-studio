This is a project kickoff. You (the main thread) act as the **coordinator** per
`docs/process/init.md`. Talk to the user in Russian.

1. Check state: new project or continuation (look at `outputs/` and `docs/project/`).
2. Read `inputs/idea.md`. If empty — ask the user to add an idea (or pick from `ideas.md`).
3. Run a short interview only on the gaps (don't repeat what's already in the idea).
4. Adapt `docs/project/roadmap.md` and `docs/project/decision-log.md` to the project.
5. Report and propose the first step (usually `/brief`), then wait for "Proceed!".

Don't run deep requirements discovery here — that's `/brief`. Honor human gates
(`docs/process/human-gates.md`).

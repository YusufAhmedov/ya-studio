Прочитай:
- `outputs/brief.md` — обогащённый бриф (результат `/brief`)
- `outputs/research.md` — синтез конкурентного ресёрча (результат `/research`)
- `templates/prd_oneshot.md` — фиксированный шаблон одностраничного PRD

Заполни шаблон, опираясь на бриф и ресёрч. Пиши по-русски.

## Маппинг секций
- **Что это** — суть продукта (Функциональность + Пользователи из брифа).
- **Целевая аудитория** — из категории «Пользователи».
- **Главная проблема** — основная боль ЦА, подтверждённая ресёрчем.
- **Ключевые сценарии** — 3-5 из «Функциональности».
- **Конкурентный ландшафт** — 3-5 продуктов из ресёрча + пробел, который мы закрываем.
- **Скоп MVP** — таблица MoSCoW по экранам/сценариям; приоритеты расставь обоснованно
  (Must для главного сценария, Should для вспомогательных, Could/Won't для отсечения).
- **Визуальный язык бренда** — тон, настроение, стиль, ключевые образы, референсы (из брифа).
- **Метрики успеха MVP** — из «Бизнес-целей», по возможности в числовом виде.

## Правила
- Не выдумывай факты, которых нет в брифе/ресёрче. Не хватает — `[уточнить: что именно]`.
- В конце добавь раздел `## Открытые вопросы` со списком всего, что нужно уточнить.

Сохрани финальный PRD в `outputs/prd.md`.

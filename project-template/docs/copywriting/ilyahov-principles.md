# Принципы сильного текста — Ильяхов «Пиши, сокращай 2025»

Извлечённые принципы для UX-копирайтинга. Источник: книга Максима Ильяхова и Людмилы Сарычевой.

---

## 1. Стоп-слова — удаляй без потери смысла

Стоп-слова — языковой мусор. Если слово можно убрать без потери смысла — убирай.

**5 групп стоп-слов:**
- **Вводные конструкции:** «безусловно», «разумеется», «скажем так», «к сожалению», «в общем-то» → удалить
- **Навязанные оценки:** «невероятное качество», «выгодные условия», «удобный сервис» → заменить фактами
- **Штампы:** «лидер рынка», «надежный партнер», «работаем для вас» → заменить конкретикой
- **Заумное:** бюрократический язык, номинализации → перевести в глаголы
- **Неопределённое:** «в связи с обстоятельствами», «в ближайшее время» → конкретные данные

**Пример:**
```
❌ Вы должны обязательно зарегистрироваться, прежде чем мы сможем продолжить оформление заказа.
✅ Зарегистрируйтесь, чтобы мы знали, когда и куда доставить заказ.
```

---

## 2. Оценка без факта = пустой текст

Прилагательные («быстрый», «качественный», «надёжный») не убеждают — они декларируют.
Каждую оценку нужно заменить или дополнить фактом.

**Формула:** оценка → конкретный факт, который читатель может проверить.

```
❌ Быстрая доставка
✅ Доставка за 2 часа по Душанбе

❌ Выгодные условия рассрочки
✅ Рассрочка на 12 месяцев без переплат — Alif Pay

❌ Удобный сервис
✅ Заказывайте в приложении — оператор перезвонит за 5 минут

❌ Эффективная система
✅ Конверсия выросла на 20% за первый месяц

❌ Качественный продукт
✅ Ювелирные украшения из серебра 925 пробы
```

**Важно:** факт должен быть понятен читателю. «Диагональ 13,4 дюйма» — пустой факт. «Немного больше листа А4» — понятный факт.

---

## 3. Глаголы вместо существительных

Отглагольные существительные (номинализации) → глаголы. Активный залог вместо пассивного.

```
❌ Осуществление регистрации возможно после оплаты.
✅ Зарегистрируйтесь после оплаты.

❌ Обеспечение доставки производится в течение суток.
✅ Доставим за сутки.

❌ Оформление заказа
✅ Оформить заказ / Заказать
```

**UX-применение:** кнопки всегда начинаются с глагола в инфинитиве.

---

## 4. Один элемент — одна мысль

- Одно предложение = одна мысль. Читается на одном дыхании.
- Один абзац = одна тема. Первое предложение заявляет тему.
- Один экран = одно главное действие.
- Один CTA = один призыв.

```
❌ В связи с невозможностью оперативного реагирования финансовой службой на запросы, связанные с внеплановыми выплатами...
✅ Если в следующем месяце планируете премии — сообщите в финансовую службу до пятницы.
```

---

## 5. Показывай кино, а не явления

Текст с людьми и действиями читается лучше, чем текст с абстракциями и явлениями.

**Формула:** кто + делает что + зачем/в какой ситуации

```
❌ Возможность делиться рекомендациями с друзьями.
✅ Понравилось кафе? Отметьте его и поделитесь с друзьями — удобно при совместном планировании.

❌ Функция добавления в избранное.
✅ Сохраните украшение, чтобы вернуться позже или показать близким.
```

---

## 6. Конкретный заголовок, а не умный

Заголовок должен сообщать суть, а не интриговать. Ключевые слова — в начало.

```
❌ Не упустите шанс!
✅ Скидка 20% на золотые украшения — до 30 июня

❌ Новинки уже здесь
✅ Новая коллекция летних украшений — 45 моделей

❌ Ваш заказ
✅ Заказ №4521 оформлен — доставка 15 июня
```

---

## 7. Тональность — нейтральная и уважительная

Выбор тональности зависит от нужной реакции. В большинстве UI-ситуаций — **нейтральная**.

| Ситуация | Тональность | Пример |
|---|---|---|
| Ошибка, блокировка | Нейтральная, помогающая | «Неверный код. Запросите новый.» |
| Пустое состояние | Нейтральная, ободряющая | «Здесь пока ничего нет. Добавьте первый товар.» |
| Успех | Нейтральная, позитивная | «Товар добавлен в корзину.» |
| Онбординг | Дружелюбная, прямая | «Добавьте первый товар, чтобы начать» |

**Избегать:**
- Назидательного тона: «Не забудьте заполнить все поля!»
- Корпоративного официоза: «Настоящим уведомляем вас...»
- Восклицаний там, где их не ждут: «Добро пожаловать!!!»

## 8. Прямо — что, зачем, что дальше

Структура сообщения для любого UI-текста:
1. **Что произошло / что это** — факт
2. **Почему важно** — только если неочевидно
3. **Что делать** — следующий шаг

```
❌ Ошибка
✅ Не удалось подключиться. Проверьте интернет и попробуйте снова.

❌ Требуется авторизация
✅ Войдите, чтобы сохранить украшение в избранное.

❌ Нет результатов
✅ По запросу «кольцо с рубином» ничего не найдено. Попробуйте «кольцо с камнем».
```

## 9. Промостраница / карточка товара — от желаний читателя

Не «вот наш продукт», а «вот как он решает твою задачу».

Правильный порядок:
1. Желания, цели, опасения читателя
2. Как продукт отвечает на них — с фактами и визуализацией
3. Ответы на возможные вопросы
4. Призыв к действию

```
❌ Кольцо из серебра 925 пробы. Вес 4.2г. Размер 17.
✅ Кольцо на каждый день — лёгкое (4.2г), не царапается, серебро 925 пробы.
   Подойдёт под деловой образ и вечерний.
```

## 10. UX-специфика — применение принципов

### Кнопки (verb + object, ≤3 слов)
```
✅ Добавить в корзину | Оформить заказ | Войти | Сохранить | Отмена | Попробовать бесплатно
❌ Кликните здесь | OK | Подтверждение | Нажмите для продолжения
```

### Пустые состояния (что + почему + действие)
```
✅ Корзина пуста. Добавьте товары из каталога.
✅ Ещё нет заказов. Оформите первый — доставим за 2 часа.
❌ Нет данных | Список пуст | Здесь ничего нет
```

### Ошибки (что случилось + что делать)
```
✅ Неверный код. Запросите новый или проверьте SMS.
✅ Карта не привязана. Добавьте карту в разделе «Оплата».
❌ Ошибка | Что-то пошло не так | Попробуйте позже
```

### Состояния загрузки
```
✅ Загружаем товары… | Ищем лучшую цену… | Оформляем заказ…
❌ Loading… | Пожалуйста, подождите | Обработка
```

### Подтверждения
```
✅ Товар добавлен в корзину | Заказ оформлен | Сохранено
❌ Успех! | Готово! | Операция выполнена
```

### Подсказки и onboarding
```
✅ Нажмите «Избранное», чтобы вернуться к украшению позже.
❌ Добавьте в избранное!
```

## 11. UX-паттерны поверх базовых принципов

*(Источники: Ozon Tech UX Writing Guide, vc.ru, habr.com, Nielsen Norman Group)*

### Паттерн: пустое состояние
Структура: **[Что сейчас] → [Почему] → [Что делать] → [CTA]**
```
✅ Заказов пока нет. Найдите что-нибудь в каталоге. → [Перейти в каталог]
✅ Корзина пуста. Добавьте товары, чтобы оформить заказ. → [В каталог]
❌ Нет данных | Список пуст
```

### Паттерн: ошибка
Структура: **[Что пошло не так, конкретно] → [Почему] → [Как исправить]**
```
✅ Карта не прошла. Недостаточно средств. Попробуйте другую карту или пополните баланс.
✅ Неверный код. Проверьте SMS или запросите новый.
❌ Произошла ошибка | Попробуйте позже | Что-то пошло не так
```

### Паттерн: экран подтверждения (confirmation)
- Заголовок — утверждение, **не вопрос** «Вы уверены?»
- Кнопки называют конкретное действие: **«Удалить» / «Оставить»**, никогда «ОК» / «Отмена»
- Нет двойных отрицаний в тексте
```
❌ Вы уверены, что хотите удалить товар? [ОК] [Отмена]
✅ Удалить товар из корзины? [Удалить] [Оставить]
```

### Правило: headline + кнопка = одно предложение
Тест: закрой всё кроме заголовка и кнопки — смысл должен быть ясен.
Тест кнопки (Ozon): «Окей, [текст кнопки]» — должно звучать естественно.
```
✅ «Окей, добавить в корзину» — работает
✅ «Окей, оформить заказ» — работает
❌ «Окей, оформление» — нет
❌ «Окей, далее» — нет
```

### Правило: позитивный фрейминг
Переформулируй потерю в выгоду или нейтральный факт.
```
❌ Данные исчезнут через 5 дней
✅ Доступно ещё 5 дней

❌ Срок хранения истекает
✅ Заберите заказ до пятницы
```

### Правило: ссылки — information scent (NN/G)
Текст ссылки = описание результата перехода. Пользователь должен знать куда попадёт.
```
❌ Подробнее | Узнать | Здесь | Нажмите
✅ Правила возврата | Все фильтры | Условия рассрочки | Другие размеры
```

### Правило: первое слово — главное (F-pattern, NN/G)
Пользователи читают первые 2–3 слова строки и принимают решение читать дальше.
В списках и коротких блоках — самое важное слово стоит первым.
```
❌ Также вы можете отследить статус заказа в приложении
✅ Статус заказа — в приложении Alif
```

### Правило: разрешения объясняются пользой
При запросе доступа (геолокация, камера, уведомления) — одно предложение о пользе для пользователя.
```
❌ Разрешить доступ к геолокации?
✅ Разрешите геолокацию — покажем магазины рядом с вами.
✅ Включите уведомления — сообщим о снижении цены на избранное.
```

## Чеклист перед финалом

- [ ] Каждое прилагательное подкреплено фактом или удалено
- [ ] Все вводные конструкции проверены и убраны лишние
- [ ] Кнопки начинаются с глагола
- [ ] Ошибки объясняют что случилось + что делать
- [ ] Пустые состояния предлагают следующий шаг
- [ ] Нет слов «уведомляем», «настоящим», «в связи с»
- [ ] Нет восклицаний там, где их не ждут
- [ ] Каждое предложение читается на одном дыхании

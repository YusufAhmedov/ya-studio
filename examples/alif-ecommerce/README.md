# Пример: Alif Tech E-Commerce

Это **заполненный пример** всех артефактов пайплайна — реальный прогон по
продукту Alif Tech E-Commerce (SaaS-платформа для интернет-магазинов в Таджикистане).

Используй его как референс «как должен выглядеть результат каждого этапа»:

- [`idea.md`](idea.md) — сырая идея на входе (что кладётся в `inputs/idea.md`)
- [`brief.md`](brief.md) — обогащённый бриф после `/brief`
- [`research.md`](research.md) — конкурентный синтез после `/research`
- [`prd.md`](prd.md) — одностраничный PRD после `/prd`

Макеты этого примера собраны в Figma (5 экранов: админка + витрина магазина).

> Когда начинаешь новый проект — не трогай эту папку. Она нужна только как образец.
> Свои артефакты пайплайн складывает в `outputs/`.
